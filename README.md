# Solace – Sito

Sito web di Solace Real Estate Short Rent, rivolto ai proprietari di immobili.
Realizzato con [Next.js](https://nextjs.org) (App Router, TypeScript).

## Avvio in locale

Requisiti: Node.js 20 o superiore.

```bash
npm install
npm run dev
```

Poi apri http://localhost:3000.

## Dove modificare i contenuti

- `lib/site.ts` – contatti, servizi, passaggi, casi studio e foto degli immobili
- `app/page.tsx` – struttura della pagina e testi principali
- `app/globals.css` – colori e stile
- `public/images/` – foto
